- Navigate ไปหน้า "ผลการดำเนินงาน" (Performance) → เลื่อนไปหาส่วน "รายละเอียด" ที่มี 4 tabs (ครีเอเตอร์/สินค้า/วิดีโอ/ไลฟ์สตรีม) สำเร็จ

### จุดที่ล้มเหลว
- เมื่อกด "ดาวน์โหลด" ในแผง "รายงานที่ส่งออก" — API call `export_task/export` คืนค่า **HTTP 503 (Service Unavailable)** ทุกครั้ง ไม่มีข้อยกเว้น
- ทดสอบซ้ำ 4 ครั้ง ครอบคลุมทั้ง task_id ใหม่ (สร้างวันนี้) และ task_id เก่า (สร้างเมื่อวาน 04/08 ที่เคยดาวน์โหลดได้มาก่อน) — **ทุกคำขอคืน 503 เหมือนกันหมด**
- Tab ครีเอเตอร์ที่กด export ใหม่วันนี้ ค้างสถานะ "กำลังส่งออก" นานกว่า 12 นาที ไม่เสร็จเลย (ปกติ 60-90 วินาที)
- สรุปได้ชัดเจนว่าเป็นปัญหาฝั่ง TikTok server ไม่ใช่ปัญหาการตั้งค่าหรือ automation ฝั่งเรา
- ไม่มีไฟล์ .xlsx ใหม่ปรากฏใน Downloads เลย (ตรวจสอบด้วย network log + ls Downloads)
