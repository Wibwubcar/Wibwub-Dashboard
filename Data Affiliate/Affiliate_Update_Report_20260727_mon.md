## ⚠️ หมายเหตุ / ปัญหาที่พบ (สำคัญ — ควรอ่าน)

**1. วีดีโอ export ล้มเหลว (503 ต่อเนื่อง)**
ลอง trigger export ใหม่ 2 ครั้ง (job คนละ ID) และ retry การดาวน์โหลดหลายรอบ (รวม wait นานสุด ~25 วินาทีต่อครั้ง) — ทุกครั้งได้ `HTTP 503` จาก `affiliate.tiktok.com/api/v1/insights/export/file/...` ยืนยันผ่าน network log ว่าเป็นปัญหาฝั่ง TikTok server ไม่ใช่ UI — ปัญหานี้ตรงกับที่เคยพบในรายงานวันก่อนหน้าด้วย (recurring issue) แนะนำให้ลองรันใหม่รอบถัดไป หรือ manual download

**2. Live-stream export ไม่มีในหน้าใหม่ของ TikTok**
TikTok เปลี่ยน UI ของ Affiliate Center แล้ว — หน้า "Transaction Analysis" แบบ 4-tab เดิมถูกยกเลิก แยกเป็นหน้าย่อยใต้เมนู "การวิเคราะห์" แทน (ครีเอเตอร์, สินค้า, วิดีโอ) และ**ไม่มีหน้า/export สำหรับไลฟ์สตรีมอีกต่อไป** (ยืนยันด้วยการ redirect ไป Performance page) — นี่เป็นข้อจำกัดถาวรของแพลตฟอร์ม ไม่ใช่ bug ชั่วคราว **ควรอัปเดต SKILL.md ให้ตรงกับ UI ใหม่และตัด step ไลฟ์สตรีมออก หรือหาทางเลือกอื่น**

**3. แก้ column mapping ของไฟล์ครีเอเตอร์ (ปรับจาก SKILL.md เดิม)**
โครงสร้างคอลัมน์จริงในไฟล์ export ปัจจุบันไม่ตรงกับที่ระบุใน SKILL.md (col[2]=returns, col[10]=commission) — คอลัมน์จริงคือ:
- col[1] = GMV จากแอฟฟิลิเอต (ตรงกับที่ระบุ)
- col[7] = ค่าคอมมิชชั่นโดยประมาณ (ไม่ใช่ col[10] ซึ่งจริงๆคือ "โชว์เคสสินค้า")
- col[21] = GMV ของการคืนเงินจากแอฟฟิลิเอต (ไม่ใช่ col[2] ซึ่งจริงๆคือ GMV จาก LIVE)

ยืนยันความถูกต้องด้วยการเทียบกับตัวเลขบนหน้า TikTok เอง (GMV ฿1,274,236.29 และค่าคอมมิชชั่น ฿146,957.58 ตรงกันเป๊ะ) **แนะนำให้แก้ SKILL.md ให้ map ตามชื่อ column (header-based) แทน index ตายตัว เพื่อกันปัญหานี้เกิดซ้ำ**
