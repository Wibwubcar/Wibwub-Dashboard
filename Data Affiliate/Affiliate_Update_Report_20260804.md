# WIBWUB Affiliate Update — 2026-08-04

## ❌ ล้มเหลว — TikTok Affiliate Center download endpoint ล่ม (503)

**สถานะ:** ตั้งค่าและ trigger export สำเร็จ แต่ **ดาวน์โหลดไฟล์ไม่ได้เลยสักไฟล์เดียว**

### สิ่งที่ทำสำเร็จ
- เชื่อมต่อ Chrome บน Mac (deviceId b75a6bb0...) สำเร็จ
- Navigate ไปหน้า Transaction Analysis สำเร็จ — **หมายเหตุ: หน้านี้ถูกปรับ UI ใหม่** ย้ายจาก URL เดิม `/insights/transaction-analysis` ไปรวมอยู่ในหน้า "ผลการดำเนินงาน" (Performance) ที่ URL เดิม แต่เนื้อหาเปลี่ยน — เมนู "ครีเอเตอร์" เดิมในซ้ายมือ (แยกหน้า) ถูก deprecate แล้ว (ระบบแจ้ง "หน้านี้จะเลิกใช้งานเร็วๆ นี้") ตอนนี้ตาราง ครีเอเตอร์/สินค้า/วีดีโอ/ไลฟ์สตรีม ทั้ง 4 อยู่เป็น tabs ในส่วน "รายละเอียด" ของหน้า ผลการดำเนินงาน — โครงสร้าง/ปุ่มส่งออกยังทำงานเหมือนเดิม
- ตั้งช่วงวันที่กำหนดเอง 01/08/2026 - 03/08/2026 สำเร็จ (03/08 คือวันล่าสุดที่มีข้อมูล)
- กด "ส่งออก" (export) ครบทั้ง 4 tabs สำเร็จ — ระบบ TikTok แจ้ง "ระบบเตรียมข้อมูลสำเร็จแล้ว" (export task สร้างสำเร็จ)

### จุดที่ล้มเหลว
- เมื่อกด "ดาวน์โหลด" ในแผง "รายงานที่ส่งออก" ทุกครั้ง (ลองทั้งไฟล์ที่เพิ่ง export และไฟล์เก่าที่เคย export สำเร็จมาก่อนหน้านี้ในวันเดียวกัน, ลองทั้ง 4 tabs, ลอง reload หน้าใหม่ทั้งหมด) — **API call `export_task/export` คืนค่า HTTP 503 (Service Unavailable) ทุกครั้ง ไม่มีข้อยกเว้น**
- ลองซ้ำทั้งหมด 7+ ครั้ง คนละ task_id คนละ tab (ครีเอเตอร์, ไลฟ์สตรีม) ผลลัพธ์เหมือนกันหมด → สรุปว่าเป็นปัญหาฝั่ง TikTok server ไม่ใช่ปัญหาการตั้งค่าฝั่งเรา
- ไม่มีไฟล์ .xlsx ใหม่ปรากฏใน Downloads เลย
