## บั๊กที่แก้ถาวรแล้วรอบนี้

**1. `scripts/vid_merge.py` ใช้ `date.today().month`** — วันนี้ 1 ก.ย. ถ้าไม่แก้จะสร้างคอลัมน์ `sep` แล้วยัดยอด ส.ค. ลงไป แก้ให้ดึงเดือนจากช่วงวันที่ในชื่อไฟล์แทน (`...-20260830` → `aug`) มี fallback เป็น `date.today()` พร้อม warning ถ้าชื่อไฟล์ไม่มีวันที่

**2. path ใน `vid_merge.py` hardcode session เก่า** (`/sessions/beautiful-ecstatic-ride/...`) ซึ่งพังทุกครั้งที่ session เปลี่ยน แก้ให้คำนวณจากตำแหน่งไฟล์สคริปต์เอง (`__file__` → parent) ใช้ได้ทุก session

**3. คอลัมน์ในไฟล์ครีเอเตอร์ไม่ตรงกับที่ SKILL.md ระบุ** SKILL บอก col 2=คืนเงิน / 3=ออเดอร์ / 10=คอมมิชชั่น แต่จริงคือ **col 1=GMV, col 4=คืนเงิน, col 21=คอมมิชชั่น** (col 10 คือ CTOR เป็นเปอร์เซ็นต์ ถ้าใช้จะได้ 24,952) และต้องข้าม header 2 แถว (`.iloc[2:]`) ไม่ใช่ 1 แถว ยืนยันถูกต้องด้วยการ cross-check กับผลรอบเช้าที่รู้ค่าแล้ว ตรงเป๊ะทั้ง 3 คอลัมน์ **ควรแก้ SKILL.md ให้ตรงความจริง**

**4. ไฟล์ครีเอเตอร์เล็กลงผิดสังเกต** — 455 KB / 5,502 แถว ทั้งที่รอบเช้าช่วงสั้นกว่าได้ 646 KB / 7,805 แถว ตรวจแล้วไม่ใช่ไฟล์เสีย TikTok แค่ตัดครีเอเตอร์ที่ GMV = 0 ออก ยอดรวมยังเพิ่มขึ้นปกติ
