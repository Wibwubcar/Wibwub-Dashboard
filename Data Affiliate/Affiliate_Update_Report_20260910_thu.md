# 🐛 บั๊กใน skill ที่ควรแก้

**STEP 4 — column index ผิด**

ไฟล์ export จริงมี **2 แถว header** (แถว 0 = ชื่อคอลัมน์, แถว 1 = คำอธิบายภาษาไทยยาวๆ) และมี 22 คอลัมน์ ทำให้สคริปต์ตามที่ skill เขียนไว้ crash:

```
ValueError: could not convert string to float: 'GMV ที่เกิดจากลูกค้าที่แตะลิงก์สินค้า...'
```

| ค่า | skill บอก | จริง |
|---|---|---|
| การคืนเงิน | col 2 | **col 4** |
| ค่าคอมมิชชั่นโดยประมาณ | col 10 | **col 21** |
| แถวข้อมูลเริ่ม | `iloc[1:]` | **`iloc[2:]`** |

วิธีที่ควรใช้แทน (ทนต่อการเปลี่ยนคอลัมน์):

```python
raw = pd.read_excel(fp, header=None)
hdr = [str(x) for x in raw.iloc[0].tolist()]
i_gmv = hdr.index('GMV จากครีเอเตอร์')
i_ret = hdr.index('การคืนเงิน')
i_com = hdr.index('ค่าคอมมิชชั่นโดยประมาณ')
df = raw.iloc[2:]
```

ตรวจกับไฟล์เก่า `20260901-20260906.xlsx` แล้ว layout เหมือนกัน → เป็นเอกสาร skill ที่ล้าสมัย ไม่ใช่ไฟล์เปลี่ยน

**STEP 5 — คอลัมน์ vid ผิด**

`vid` ต้องใช้ col 9 `'วิดีโอ'` ไม่ใช่ col 13 `'วิดีโอที่มียอดขาย'` (`cr` = col 19 `'ครีเอเตอร์ที่มียอดขาย'`) ยืนยันโดยเทียบย้อนกับค่าที่มีอยู่บน dashboard

**STEP 5B — `date_label()` ทำให้เกิด churn**

ฟังก์ชันคืนค่า `''` เมื่อ monthly ทุกเดือนเป็น 0 ทำให้ลบ label `date:'ก.ย.'` ของคลิปที่ยังไม่มียอดขายทิ้ง ควรเก็บ label เดิมไว้ถ้าคำนวณใหม่ได้ค่าว่าง
