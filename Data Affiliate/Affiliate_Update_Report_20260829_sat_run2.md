## หมายเหตุ / ข้อสังเกต
1. **รายงานรอบก่อนมีตัวเลขไม่ตรงไฟล์จริง** — รายงาน 20260829_sat อ้างว่าเขียน GMV 1,426,449 / NET 1,403,152 / COM 163,882 แต่ในไฟล์จริงคือ 1,426,267 / 1,402,970 / 163,496 ไม่มีผลกระทบเพราะรอบนี้เขียนทับ index เดิมอยู่แล้ว
2. **แผงรายงานไม่ refresh เอง** — ค้างที่ "กำลังส่งออก" ~8 นาที ต้อง reload หน้า (F5) จึงจะขึ้น "ดาวน์โหลด" (ยืนยันบั๊กเดิมข้อ 6)
3. **การ reload รีเซ็ตช่วงวันที่** กลับเป็น "7 วันที่ผ่านมา" แต่งานที่คิวไว้แล้วยังใช้ช่วงเดิมถูกต้อง (ยืนยันจากชื่อไฟล์)
4. **คอลัมน์ไฟล์ครีเอเตอร์ไม่ตรง skill** — อ่านโดยอ้างชื่อหัวคอลัมน์แทน index (GMV=1, การคืนเงิน=4, ค่าคอมมิชชั่น=21)
5. **`vid_merge.py` มี path ของ session เก่า** (`beautiful-ecstatic-ride`) ต้อง sed เป็น session ปัจจุบันก่อนรันทุกครั้ง — ควรแก้ให้อ่านจาก env หรือ argv
6. **Live GMV อัปเดตเพิ่มเอง** — skill ไม่ได้สั่ง แต่ KPI นี้ hardcode ไว้และค้างเป็นข้อมูลเก่า จึงอัปเดตให้ตรงไฟล์ไลฟ์สตรีมรอบนี้
