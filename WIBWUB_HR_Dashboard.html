🔔 Line Notify (แจ้งเตือนการอนุมัติใบลา)

เชื่อมต่อ Line Notify ผ่าน Google Apps Script เพื่อส่งแจ้งเตือนเมื่ออนุมัติ/ปฏิเสธใบลา

📋 GAS Script ตัวอย่าง (วาง → Deploy → เอา URL)
function doPost(e) {
  try {
    var body = JSON.parse(e.postData.contents);
    var token = PropertiesService.getScriptProperties()
                  .getProperty('LINE_NOTIFY_TOKEN');
    if (!token) return reply({ok:false,error:'No token set'});
    UrlFetchApp.fetch('https://notify-api.line.me/api/notify', {
      method: 'POST',
      headers: {
        'Authorization': 'Bearer ' + token,
        'Content-Type': 'application/x-www-form-urlencoded'
      },
      payload: 'message=' + encodeURIComponent(body.message),
      muteHttpExceptions: true
    });
    return reply({ok: true});
  } catch(err) { return reply({ok:false,error:err.message}); }
}
function doGet(e){ return reply({ok:true,status:'WIBWUB HR Proxy OK'}); }
function reply(o){ return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }
/* Script Properties → LINE_NOTIFY_TOKEN = your_token */
🔑 วิธีตั้งค่า Line Notify
  1. ไปที่ notify-bot.line.me → เลือกกลุ่ม HR → สร้าง Token
  2. เปิด script.google.com → New Project → วาง code ด้านบน
  3. Project Settings → Script Properties → เพิ่ม key: LINE_NOTIFY_TOKEN = token ที่ได้
  4. Deploy → New Deployment → Web App → Execute as: Me → Access: Anyone → Deploy → Copy URL
  5. วาง URL ในช่อง GAS Proxy URL แล้วกด "ทดสอบ"
